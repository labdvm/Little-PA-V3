# Little-PA-V3
Same as Little PA with few corrections and improvements
# Changes to this version:
- Added more bigger vias for better ventilation.
- Added 6dB attenuator between SX1255 and TQP3M9036 PA chip for better linear amplification.
- Re-routed power supply trace for the PA power supply.
- Changed some components value's in the BOM file.
